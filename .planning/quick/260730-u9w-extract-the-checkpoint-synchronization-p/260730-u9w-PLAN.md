Move the emulator-synchronisation primitives out of `tools/recover.mjs` into a new sibling module `.claude/skills/vice-session/scripts/vice-sync.mjs`, and have `recover.mjs` import them. Pure refactor: no behaviour change, no signature change, no simplification.

The deleted `waitPaused()` helper is precisely the bug that happens when a primitive drifts away from the rationale that shaped it. Keeping the code and its rationale in one module makes that class of regression structurally harder, and lets Phase 3's verification harness reuse the primitives without importing a Bruce-Lee-specific recovery tool.
