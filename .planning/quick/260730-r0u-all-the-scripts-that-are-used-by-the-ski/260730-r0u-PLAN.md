<objective>
Relocate every `.mjs` module used by the four project skills into a `scripts/`
subdirectory of its own skill, preserving behaviour exactly.

Purpose: one predictable place per skill for executable code, so a skill
directory reads as `SKILL.md` + data + `scripts/` rather than a flat pile.

Output: 10 relocated modules across 4 skills, every path anchor and import
specifier corrected, 2 new regression tests that fail if a path anchor is ever
wrong again, and every live documentation citation updated.

**This is a pure refactor. The risk is not the move — it is path resolution.**
Three of the affected modules resolve something by walking up from their own
module directory, and one of those failures (`install-resources.mjs`'s
`RESOURCES_DIR`) is *completely silent* by design: `ensureResourcesInstalled()`
never throws, so a wrong `resources/` path would leave every command
"succeeding" while nothing is ever deployed. That is the exact failure class
`repo-root.mjs`'s own header comment was written to prevent — read it before
touching that file.

**No gate in this plan touches the emulator.** Every verification is offline,
which matters because STATE.md records the host VICE MCP server as a HARD
BLOCKER (down). This task is fully executable while VICE is unavailable.
