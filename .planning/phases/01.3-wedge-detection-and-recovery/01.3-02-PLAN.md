<objective>
Give an agent that suspects the emulator is stuck a mechanical answer: which of five states it is in,
what evidence says so, and — when the machine stopped itself — exactly what pinned it.

Purpose: CONTEXT.md § Phase Boundary puts detection at the centre of gravity and recycle at the
fallback, which inverts the roadmap's emphasis. D-13 is why: a self-inflicted checkpoint trap looks
identical to a wedge from the outside, is cheaper to detect, is more likely to be the actual recorded
cause, and recycling it destroys a healthy instance. So the trap check runs first, before any resume,
and the destructive tool stays a separate deliberate act.

Output: a read-mostly `vice_diagnose` MCP tool served proxy-local, a single definition of the cycle
bracket, a live IRQ-handler resolver both this plan and plan 04 read, and a closed verdict vocabulary
that a future phase cannot quietly widen.
</objective>

**Correction carried from planning, load-bearing for this plan.** D-15's remediation guidance reads
as if delete-and-resume normally works. Incident 1's own step log
(`.planning/todos/pending/2026-08-01-vice-registers-frozen-after-reset-during-01-04-task2.md`,

checkpoint releases it. A test asserts the not-guaranteed statement is present.

**Two decisions this plan makes that change the shape criterion 1 describes, recorded rather than
smoothed over.**

1. **The roadmap's third state, "degraded but live", gets no verdict of its own.** D-08 forbids a
   degradation threshold, and a verdict named for degradation cannot be computed without one — that is
   the same trap this project already refused when the drift discriminator's block-fill heuristic
   scored 134/137 and was rejected anyway. The state is represented as the `live` verdict carrying a
   measured cycles-per-second observation beside the ~991,000/s baseline. It is distinguished by the
   number, never by a manufactured cut. Criterion 1's requirement — that the ~6,000/s figure is a
   distinct state and must not be recovered as one — is satisfied, because no verdict routes to
   recycle at all: recycle never gates on a verdict (D-03).
2. **The vocabulary is five members**, not the roadmap's three or D-13's implied four: `restarted`,
   `checkpoint_trap`, `wedged`, `stale_read_path`, `live`. `stale_read_path` is criterion 3's
   classification made into a first-class answer rather than a caveat in prose.

**Ordering is a decision, not an implementation detail.** D-14 modifies criterion 2's ordering: the
cycle bracket remains the definitive liveness test but is no longer the first move. The epoch check
comes before even the trap check, because it costs no emulator call at all and it is criterion 1's
already-handled case.

recorded OPEN in `01.1-deferred-items.md`. A red there is the known flake, not damage from this plan;
re-run and record both outcomes.
