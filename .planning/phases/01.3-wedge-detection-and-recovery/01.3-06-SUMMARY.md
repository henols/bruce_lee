## The topology adaptation, stated rather than glossed

The plan text was written against a topology where `vice-supervisor.sh` was a standalone per-instance
host process outliving broker restarts. Phase 01.6 **collapsed that inward**: the broker is now the one
process that spawns, supervises and respawns every instance, and `handleExit()` in `broker-launch.mts`
is what used to be the shell daemon's loop. `resources/vice-supervisor.sh` no longer exists on disk.

The mechanism these tools depend on — kill the child, an exit handler respawns it on the same port with
a bumped epoch — is **unchanged in substance**; only the implementing file and process changed. The
recorded answers cite the current TypeScript locations, not the retired shell script the original plan
text names. The ROADMAP carried an explicit warning to re-read this plan against today's architecture
before executing it, and that warning was honoured rather than executed past.
