  <action>
Complete the TCP client the tracer started, additively. Delete nothing in this task: the proxy still
runs on the file protocol until plan 07, and the suite must stay green at every commit.

Session shape: one function opens a session, reading the discovery record exactly once for the
control host, port and token — that single read is criterion G's whole point, and re-reading per
request would reintroduce a per-call filesystem dependency the transport exists to remove. Classify
the record through the existing liveness classifier first and return a typed failure without
connecting when it reads never-started or stale, so a broker that was never brought up produces a
diagnosis rather than a connection refusal. Open one connection and hold it for the session's
lifetime: the connection IS the lease, so there is nothing to heartbeat and nothing to sweep.

Request correlation: send each request as one JSON line carrying a request id and the token, and
settle the matching response by that id. Keep the ids in the existing validated shape and keep
using the existing generator, so the pattern and its validator stay the single copy this repository
has.

Framing on the read side: buffer inbound bytes and split on newline, so two responses arriving in one
chunk are both delivered and one response split across chunks is delivered once. A line that fails to
parse, or parses to something that is not an object, settles its pending request as a protocol
failure — never an exception escaping the client, matching this module's established never-throw
posture toward untrusted input.

Deadlines: give the connect attempt, acquire and recycle each their own bound. Carry the existing
values forward unchanged rather than re-tuning them — the acquire bound takes the value the retiring
grant poll used and the recycle bound takes the value the retiring acknowledgement poll used.
Choosing final values against the measured tool-call budget is explicitly Phase 01.6.2.1's item, not
this phase's; this plan relocates the constants and changes neither number. Record that in the
module's comment so the numbers are not read as freshly chosen.

Broker-gone outcome: when the socket closes or errors while requests are in flight, settle all of
them with a distinct outcome naming the broker as gone. This must be tellable apart from a
request-level error, because plan 08's discipline for broker death depends on the distinction — and
because the tolerance decision behind this transport is explicit that broker death takes the session
with it. That is accepted, not overlooked.

Release: close the connection and resolve. A second release resolves as a no-op, matching the
idempotent posture the retiring release already had, because a double teardown is the expected shape
of an interrupt followed by a terminate.

Write no file under the broker state directory from this client. The lease file, the modification-time
heartbeat convention and the interval timer that refreshed it are all retiring together, and adding
any file write back here would be exactly the second authority D-12 exists to remove.
