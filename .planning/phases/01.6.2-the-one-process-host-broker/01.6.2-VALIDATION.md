## Sampling Rate

- **After every task commit:** that slice's own per-file command from RESEARCH §E's wave breakdown
  (e.g. `node --test vice-broker.test.ts`).
- **After every plan wave:** `node --test '.claude/mcp/vice/'*.test.*` — full suite, with the
  test-count arithmetic reconciled against the 275 baseline and the slice's own declared delta.
- **Before `/gsd-verify-work`:** full suite green.
- **Phase gate (beyond a green suite):** the explicit written statement criterion E requires —
  restated under *Manual-Only Verifications* below, and reframed 2026-08-04 by Phase 01.6.2.1
  (D-19) in the "Phase 01.6.2.1 Reframing" sections appended to the end of this file. **Correctness
  is claimed against specification**, not against the retired bash daemon, with the
  genuinely-unchanged set held to real equivalence and everything else itemised as a carry-forward
  list Phase 01.4 owns.
- **Max feedback latency:** ~54 s (full suite); < 5 s (per-slice).

**Dispositions used:** REPLACED (same property, new implementation, named test exists and
passes) · RE-OBSERVED (same property, new observation point — an in-memory accessor or a
control-plane response rather than a file — named test exists and passes) · DELETED (subject no
longer exists, reason given from a named class).

**Reason classes for DELETED rows** — the six the plan-time analysis already supported (A–F),
plus eight this session's line-by-line read surfaced and named rather than stretched onto an
existing class (G–N):

| B | File-glob iteration order |
| C | Temporary-file naming detail |
| D | Command-line argument parsing for a process that no longer takes per-invocation arguments (no subcommands, no `--detach`/`--once`; the broker is one long-lived process taking exactly `--repo-root`/`--state-dir`/`--check-container`/`--dry-run`) |

| I | A bash-only structural grep against the shell source's own lack of definition-uniqueness enforcement (bash silently allows redefining a top-level function) — TypeScript's compiler makes a duplicate top-level declaration a compile error, so there is no equivalent risk in the new implementation for a test to guard against |

| L | The new wire format was designed fresh with `op` as a required field from the start (`ControlRequestKind`, `broker-control.mts`) — there is no earlier per-field-optional protocol generation left to stay backward compatible with |
| M | Deferred-grant-until-probe removed — the bash original withheld a cold-launched instance's grant until a LATER pass confirmed it via a readiness probe. A deliberate trade-off (grant fast, self-heal on first use), not a port of the deferred-grant behaviour |
| N | Supervisor-script-missing denial has no equivalent — the emulator binary is spawned directly by the broker (`child_process.spawn`, no intermediate `vice-supervisor.sh` process per D-1), so there is no sibling script path that could be missing |
