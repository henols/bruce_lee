## Sampling Rate

- **After every task commit:** that slice's own per-file command from RESEARCH §E's wave breakdown
  (e.g. `node --test vice-broker.test.ts`).
- **After every plan wave:** `node --test '.claude/mcp/vice/'*.test.*` — full suite, with the
  test-count arithmetic reconciled against the 275 baseline and the slice's own declared delta.
- **Before `/gsd-verify-work`:** full suite green.
- **Phase gate (beyond a green suite):** the explicit written statement criterion E requires —
  restated under *Manual-Only Verifications* below. A green suite here proves **language and
  structural equivalence only**.
- **Max feedback latency:** ~54 s (full suite); < 5 s (per-slice).

longer exists, reason given from a named class).

**Reason classes for DELETED rows** — the six the plan-time analysis already supported (A–F),
plus eight this session's line-by-line read surfaced and named rather than stretched onto an
existing class (G–N):

| B | File-glob iteration order |

| H | **Confirmed implementation gap, not a deliberate removal**: `handleAcquire()` (`vice-broker.mts`) never consults the warm floor at all — `state.grants.set()` has exactly one call site in the whole module, immediately following a fresh `acquirePortAndLaunch()`, with no code path that promotes an existing `state.instances` entry in state `ready` into a grant. | I | A bash-only structural grep against the shell source's own lack of definition-uniqueness enforcement (bash silently allows redefining a top-level function) — TypeScript's compiler makes a duplicate top-level declaration a compile error, so there is no equivalent risk in the new implementation for a test to guard against |

| K | `id` no longer doubles as a file/directory key — over a per-connection TCP transport, `id` is only a correlation token for matching a response to its request; a missing/unreadable one is synthesised (`defaultRequestId()`, `broker-control.mts`) rather than a fatal parse failure blocking a file write |
| L | The new wire format was designed fresh with `op` as a required field from the start (`ControlRequestKind`, `broker-control.mts`) — there is no earlier per-field-optional protocol generation left to stay backward compatible with |
| M | Deferred-grant-until-probe removed — the bash original withheld a cold-launched instance's grant until a LATER pass confirmed it via a readiness probe. | N | Supervisor-script-missing denial has no equivalent — the emulator binary is spawned directly by the broker (`child_process.spawn`, no intermediate `vice-supervisor.sh` process per D-1), so there is no sibling script path that could be missing |
