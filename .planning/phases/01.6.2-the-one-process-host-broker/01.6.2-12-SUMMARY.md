## Decisions Made

- `withCrashSupervision()` takes the full `SuperviseChildDeps` shape rather than a narrower type, deliberately never setting `spawnFactory` on the deps object either call site builds — per the plan's own action text, so a respawn's log path and its epoch record's `log` field can never disagree.
- `superviseDepsFor(stateDir, state)` is built fresh inside each spawn-factory closure (never cached), mirroring the existing per-call `MaintainWarmFloorDeps` construction pattern already in this file.
- The Task 3 gate uses an exact-equality assertion (`spawnFactoryCount === wrapperCallSiteCount`), not an "at least N" check — this was the correct choice, proven live: an "at least" check would have masked the comment-stripping trap found while authoring the gate itself (see Deviations and the third findings-log entry).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Comment-stripping trap discovered and fixed while authoring the Task 3 structural gate**

- **Found during:** Task 3 (writing the structural anti-regression gate)
- **Issue:** This plan's own Task 1/2 authored JSDoc (`/** ... */`) comments in `vice-broker.mts` happen to mention both counted tokens inline (`"Builds the supervision dependency object for withCrashSupervision(),"` and `"Deliberately does NOT set spawnFactory:..."`). The project's established `grep -v '^\s*//'` comment-stripping idiom (used correctly elsewhere for whole-line `//` comments) does not strip `/** */` block comments, so a naive count came out 3/4 instead of the real 2 — which an exact-equality assertion would report as a false failure against perfectly correct code.
- **Fix:** `stripComments()` in `broker-launch.test.ts` strips full `/* ... */` block comments (non-greedy, spanning newlines) BEFORE stripping whole `//` comment lines, rather than relying on the whole-line-only idiom alone. Whole-line-only `//` stripping is kept (never an inline trailing comment) so a string literal containing `//` (e.g. this file's own `http://127.0.0.1:<port>/mcp` construction) is never truncated.
- **Files modified:** `.claude/mcp/vice/broker-launch.test.ts`
- **Verification:** Re-ran the counts before/after the fix (3/3 raw vs. 2/2 stripped, matching the real non-comment call-site count confirmed by direct `grep -n` line inspection); the gate passes green against the actual wired code.
- **Committed in:** `00cdb51` (Task 3 commit)
