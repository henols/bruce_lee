# Phase 01.6.2 Plan 07: Swap the Proxy onto the TCP Control Plane, Delete the File Protocol Summary

**vice-proxy.ts's entire broker interaction (acquire, release, recycle) now runs over one openBrokerControl() TCP session instead of a request/grant/denial/lease/recycle-ack file tree, and that file tree's container-side implementation (vice-broker-client.ts's eight retiring functions, their constants, and six directory helpers) is deleted in the same commit, with a structural closure gate proving none of it survives anywhere in the module directory.**

## Performance

- **Duration:** ~2h30min (estimated; no precise start timestamp was captured at session start)
- **Tasks:** 3 (task 1 `type="auto" tdd="true"`, task 2 `type="auto" tdd="true"`, task 3 `type="auto"`)
- **Files modified:** 5 (4 within this plan's declared `files_modified`, plus `vice-broker.test.mjs` — see Deviations)

## Accomplishments

- **Acquisition swap (task 1):** `ensureBrokerLease()` classifies broker liveness via the unchanged `readBrokerLiveness()` first (still giving the dead-or-hung diagnosis its pid), then opens one `openBrokerControl()` session and sends one `acquire()`. On success the grant passes through the byte-unchanged `containerizeGrant()` seam and is adopted via the unchanged `useInstance()` call. The old "create a lease file before awaiting a grant" ordering constraint — load-bearing under the file protocol because the host's own sweep tore down a grant whose lease file was absent — is deleted along with its justifying comment, replaced by a comment explaining the constraint dissolved: the connection is the lease, open before the acquire is even sent, so there is no window for a sweep to observe a mismatch.
- **Release swap (task 1):** the module-level `brokerLeaseId`/`brokerHeartbeatTimer` pair is replaced by `controlSession`/`grantId`. The teardown region's `releaseLeaseNow()` now calls `controlSession.release().catch(...)` — `.catch()` rather than `await` or `.then(`, since `BrokerControlSession.release()` is declared `async` (a synchronous throw inside it becomes a rejected promise, which a bare try/catch around an unawaited call would never observe) and the teardown region's own structural oracle forbids both `await` and `.then(`.
- **Recycle swap (task 2):** `handleRecycle()`'s fixed order (epoch read, three refusals, incident-record-before-request, successful-kill classification, two-separate-facts reporting) is unchanged; only the request-write-and-poll step is replaced by one `controlSession.recycle(grantId)` call. A new `broker_gone` branch — distinct from an acknowledgement carrying a refusal — finalises the incident record with that outcome and returns text that never substring-matches the refusal phrasing. `recycleAckOutcomeMessage()` and the handler's own `async function handleRecycle(args)` declaration text are both byte-unchanged, verified by region diff and by the existing structural oracles continuing to pass unmodified.
- **Deletion (task 3):** `vice-broker-client.ts` loses `writeRequest`/`createLease`/`touchLease`/`releaseLease`/`pollGrant`/`writeRecycleRequest`/`pollRecycleAck`/`startHeartbeat` (the eight retiring functions), their record interfaces and `PollOptions`, their poll/heartbeat constants (`GRANT_POLL_TIMEOUT_MS`/`GRANT_POLL_INTERVAL_MS`/`RECYCLE_ACK_TIMEOUT_MS`/`RECYCLE_ACK_POLL_INTERVAL_MS`/`HEARTBEAT_MS`), and six directory helpers (`requestsDir`/`grantsDir`/`denialsDir`/`brokerLeasesDir`/`recycleAcksDir`/`leasePathFor`). Surviving surface (13 runtime exports, pinned by a new test): the request-id primitives, `brokerRootDir()`/`brokerJsonPath()`, `readBrokerLiveness()`/`BROKER_STALE_MS`, `acquireOverControlPlane()`'s own tracer surface (plan 01, untouched), and the full TCP control client (plan 06, untouched).
- **Structural closure gate (task 3):** a new test enumerates the module directory's non-test source (`readdirSync`, matching the idiom `vice-proxy.test.ts`'s network-call scan and `vice-broker-launch.test.ts`'s `JUSTIFIED_NETWORK_CALLERS` already use), strips `//` and `/* */` comments, and asserts none of the eight retiring functions, their constants, or their directory helpers appear anywhere. Its discriminating power was verified LIVE: a stub `touchLease()` was temporarily inserted into `vice-broker-client.ts`, the gate was re-run and confirmed to fail naming that exact identifier, then the insertion was reverted and the passing state re-confirmed.
- **Disposition-table execution (task 3):** every one of plan 06's 14 catalogued tests is accounted for — the 3 `SURVIVES` rows (`newRequestId`/`isValidRequestId`, `readBrokerLiveness` x2 additional) and the 4 `RE-OBSERVED` replacement tests (added by plan 06) are untouched; the 10 non-`SURVIVES` original tests (`writeRequest`/`createLease` x2, `touchLease` x2, `releaseLease` x2, `pollGrant` x4) are deleted here, in the same commit as their own subjects' deletion. `vice-broker-client.test.ts`: 29 → 21 tests (10 removed, 2 structural tests added).
- **Proxy test suite rebuilt onto the control plane:** every acquisition, release, containerize and recycle test in `vice-proxy.test.ts` now drives a REAL `broker-control.mts` `startControlListener()` (via new `startControlBroker()`/`acquireLeaseViaBroker()` helpers) instead of writing request/grant/denial/lease/ack files, matching the idiom plan 06 established for the client's own test file. `makeControllableRecycle()`/`makeControllableRecycleSequence()` (deferred-promise pairs) let a test control exactly when a recycle acknowledgement "arrives," including never (the timeout path) and immediately-with-file-existence-assertions (the incident-record-ordering path). The two heartbeat tests (mtime advancing, timer unref'd) are deleted outright — their subject retires with no successor to re-observe. `vice-proxy.test.ts`: 80 → 82 top-level test declarations (4 added, 2 removed).
