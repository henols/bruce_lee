<objective>
Fix every message that will otherwise tell a human or an agent to run a file this phase deletes, delete
the installer paragraph that advertises a capability whose scripts are already gone, and triage every
reference to the port number the emulator band moves away from — individually, because not all of them
are ports.

of this phase. That is Phase 01.4's criterion 5 failure shape exactly — a green suite while what a
session can actually act on is broken — arriving here without anyone asking for it. And the installer's
instructions do not need a path swapped: they advertise a standalone recovery pipeline whose scripts
were already deleted, so swapping the path would keep advertising a dead capability.

Output: every host-instruction message pointing at the surviving launcher with an invocation it
accepts, one deleted paragraph, a per-file port triage recorded in writing, and a structural gate that
stops a dead filename coming back.
</objective>
