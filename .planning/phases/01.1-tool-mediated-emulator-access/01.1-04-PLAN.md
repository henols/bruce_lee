<objective>
Prove the replacement works from a fresh session, and only then retire the Bash-mediated path —
relocating the transport module tree into the new skill and repointing every consumer, rather than
deleting anything that is still load-bearing.

Purpose: criterion 8 is a **migration**, not a deletion. The transport module is imported as a
*library* by five files that never touch Claude Code's MCP layer at all, and the host-side launch
machinery still serves the fixed port the proxy forwards to. Breaking either would strand exactly
the work Phase 1 has left to do. And the sequencing is not negotiable: removal lands only after the
fresh-session proof, because retiring access before the replacement is proven leaves no route to the
emulator.

Output: recorded criterion-3 evidence; the relocated module tree with every import repointed; the
`vice-session` skill gone; and a durable, enumeration-based completeness check standing in for the
one-shot greps that would rot silently.
</objective>
