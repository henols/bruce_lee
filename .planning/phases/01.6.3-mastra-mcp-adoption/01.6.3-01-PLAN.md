`tsconfig.build.json`'s `include` list is the host-bound set (`vice-broker.mts`,

The real cost of bundling: `@mastra/mcp` + `@mastra/core` together are **~69 MB unpacked across 35
direct dependencies**, including a triple-vendored `@ai-sdk/provider-v5`/`v6`/`v7` set (per

`.claude/mcp/vice/` — a directory whose own convention (`.claude/CLAUDE.md` § Emulator Access) is
"authored TypeScript source, siblings of `resources/`" — would mean committing someone else's
minified dependency tree as project source, requiring a NEW build toolchain (esbuild/rollup; this
repo's only existing build step, `tsc` via `build.ts`, is not a bundler and was deliberately scoped
to the host-bound files only) for a file that has never needed one, and re-bundling on every future
version bump of either package. `01.6-RESEARCH.md` §B3 already named this exact objection when the
concern was mistakenly thought to be host-side — "a bundled file is by definition NOT what was
authored" — and it applies with equal force container-side.

**Decision: do NOT bundle. Wire `npm ci` into devcontainer provisioning instead.** Add a new step
to `.devcontainer/devcontainer.json`'s `postCreateCommand`, which today reads
`"bash .devcontainer/post-create.sh && bash .devcontainer/install-acme.sh"`. Append
`&& npm ci --prefix .claude/mcp/vice` (using `npm ci`, not `npm install`, since a committed
`package-lock.json` now exists and `npm ci` is the deterministic, lockfile-exact form — matching
the exact-pin convention already established for this directory). This is essentially free: the
devcontainer already runs network-dependent provisioning steps (`install-acme.sh` fetches
`ACME_Lib` from GitHub), and this repository already needed `npm install` to run at least once for
`typescript`/`@types/node` before `tsc --noEmit`/`build.ts` would work — a real runtime dependency
does not introduce provisioning-time `npm install`, it only raises the stakes of skipping it.

**The disclosed cost, stated plainly rather than left implicit:** the "fresh clone works on bare
`node`" property is now narrower than it was. A `git clone` followed directly by
`node .claude/mcp/vice/vice-proxy.ts`, bypassing the devcontainer's own provisioning entirely, will
fail with Node's own `Cannot find module '@mastra/mcp'` until `npm ci --prefix .claude/mcp/vice`
runs once. This project's whole operating model is the devcontainer (`.claude/CLAUDE.md`:
"Everything runs headless in this Linux container" — there is no supported bare-clone-outside-a-
devcontainer path today, so this is a narrowing of an already-devcontainer-scoped property, not a
new external requirement). Record this decision, its reasoning, and this disclosed cost in a short
paragraph inside `.claude/CLAUDE.md` § Emulator Access (the tier-rules section), immediately after
the existing `.claude/mcp/` three-tier description, since that section is where a later reader
would look for "what does this directory need to run." Do not put this in a GSD-managed block —
Emulator Access is explicitly kept outside those blocks so a regeneration does not drop it.

`01.6.3-APPROVALS.md` warns against). Plan 02 imports from it as an already-resolved transitive
dependency.

Commit this task's changes together: `package.json`, `package-lock.json`, `devcontainer.json`,
