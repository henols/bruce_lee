<objective>
Convert the hub — 2,441 lines of project-specific logic — and rewire the one hardcoded path
that all emulator access depends on.

Purpose: `vice-proxy` is the file the ROADMAP singled out as needing its own plan. Its
~2,100 lines of broker leasing, epoch and liveness handling, recycle and diagnose, deny-list
enforcement, path rewriting and incident capture **must come through untouched** — Phase
01.6.3 swaps its transport seam afterwards, and doing both at once would make a regression
ambiguous in attribution.

**Its 4,370-line test file deliberately stays `.mjs` until Plan 08.** That is not an
oversight and it is not a deferral for context reasons. RESEARCH's own Pitfall 1 is that a
conversion bug landing in *both* a source file and its test at once is invisible to the
suite. For every other slice in this phase the two moved together and the pairing was the
right call because both halves were small. For the hub — the largest, most logic-dense file
in the tree — holding the test constant while the source converts turns those 4,370 lines
into an **unchanged oracle**. That is a strictly stronger equivalence proof than converting
both, and it is available here precisely because the ROADMAP already required two plans.

**Blast radius.** `.mcp.json` hardcodes the proxy's path and is read once, at session start.
A rename that does not update it in the same commit loses all emulator access at the next
session — the highest-blast-radius one-line change in the whole conversion, and the ROADMAP
names it as such. Note the mechanism recorded in `.planning/RE-FINDINGS.md`: the harness
spawns the proxy per session and a running session holds its snapshot, so **the executor's
own session will not notice a broken rewiring**. It cannot be caught by "it still works for
me." It is caught here by starting the rewired entry point directly and driving a real MCP
handshake over stdio.

Output: the hub in TypeScript, `.mcp.json` rewired, and a recorded invariant baseline the
audit compares against.

**Inherited decisions:** D-01 and D-06 are deferred to Phase 01.6.3. Converting the hub
**hand-rolled** here — its JSON-RPC framing, initialize handler and tool-call routing
skeleton written out in TypeScript rather than replaced by an SDK — is the direct consequence
of that deferral and of PATTERNS' explicit sequencing recommendation. Do not adopt or
anticipate any MCP library in this plan.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent session → `.mcp.json` → proxy entry point | Read once, at session start. A wrong path costs all emulator access, and the session that made the change cannot observe it. |
| stdin JSON-RPC → the proxy's handlers | Untrusted message shapes arrive on stdin; the proxy must narrow before reading fields. |
| proxy → host VICE | Every forwarded call crosses this; the deny-list, the epoch re-check and the path rewriting all live at this seam. |
| host reply → agent-visible output | The output ceiling chunks rather than truncates, so a large reply is never silently cut. |
