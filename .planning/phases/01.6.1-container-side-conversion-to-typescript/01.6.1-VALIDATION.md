## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Node's built-in `node:test`. No third-party runner; none introduced by this phase. |
| **Config file** | None — `node --test` globs `.test.ts` and `.test.mjs` identically (verified live). |
| **Quick run command** | `node --test <file>.test.ts` — the single converted file for the slice in flight (per-slice commands in RESEARCH §2). |
| **Full suite command** | `node --test '.claude/mcp/vice/'*.test.*` — or `npm test` from inside `.claude/mcp/vice/` (identical, already defined in `package.json`). |
| **Estimated runtime** | ~35 s for 247 tests (measured live ×2, 2026-08-03; matches `01.6-VERIFICATION.md`'s recorded baseline exactly). |

> **Corrected command.** The parent `01.6-VALIDATION.md` specified `node --test .claude/mcp/vice/src/`. That path
> references a `src/` directory that was **never adopted** — Phase 01.6's planning note rejected RESEARCH §A3's
> `src/` layout because `repo-root.mjs`'s branch-4 fallback climbs exactly three levels and `RESOURCES_DIR`
> resolves `resources/` as a plain sibling. The build topology stayed flat. Passing a nonexistent directory makes
> Node treat it as a single test file. Use the command in the table.

> **Stale config.** `.planning/config.json`'s `workflow.test_command` is also stale and undercounts by 13 tests
> (RESEARCH §6). Fixing it is a Wave 0 item below — a one-line config change, not code.

## Sampling Rate

- **After every task commit:** that slice's own per-file command from RESEARCH §2's slice table
  (e.g. `node --test vice-probe.test.ts`).
- **After every plan wave:** `node --test '.claude/mcp/vice/'*.test.*` — full suite, with the test-count
  arithmetic reconciled against the 247 baseline (a slice that converts N tests must still total 247 unless it
  deliberately adds coverage, in which case the plan states the new total).
- **Before `/gsd-verify-work`:** full suite green.
- **Phase gate (beyond a green suite):** the criterion-B fix must be proven against a **live-injected
  regression at least once during development** — not merely trusted from the test's own logic. The research
  did exactly this (removing `hostpath.mjs`'s `from: HERE` override reproduces
  `Cannot access 'HERE' before initialization` while the current `load-order.test.mjs` still reports 4/4 pass).
  Reproduce it against the landed fix.
- **Max feedback latency:** ~35 s (full suite); < 5 s (per-slice).
