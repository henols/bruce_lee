## Corrections to RESEARCH.md, found live at plan time (2026-08-03)

Four findings that change what the executor must do. They are corrections, not
contradictions — RESEARCH's structure holds; these are gaps in its measurement.

1. **`vice-probe.mjs` is NOT a leaf.** RESEARCH §2's graph records it as "0 internal deps —
   the only true leaf." It is not: `vice-probe.mjs:41` carries a bare side-effect import of
   `./repo-root.mjs`. The graph's shape is otherwise correct, and converting a dependent
   before its dependency is harmless (specifiers are extension-exact either way) — but it
   means **`vice-probe.ts` is a consumer Plan 03 must update** when `repo-root.mjs` renames.
   Plan 03's task lists it explicitly.
2. **There is a THIRD extension-hardcoded enumerator RESEARCH did not name:**
   `skill-docs.test.mjs`'s `scriptModules()` (`.filter((f) => f.endsWith(".mjs"))`, line 68).
   Once any source file renames, that file drops out of the "no module under this directory
   is named in any agent-facing doc" check — silently, exactly like `importsHostpath()`.
3. **Widening `enumerateModules()` without a `node_modules` exclusion is a trap.**
   `vice-mcp-selector-docs.test.mjs`'s `walkFiles()` (line 68) recurses with no directory
   exclusions. `.claude/mcp/vice/node_modules` holds **0** `.mjs` files but **335** `.ts`
   files (counted live). Widening the predicate to a `[cm]?[jt]s` class without excluding
   `node_modules` enumerates all 335 as "modules".
4. **Widening `scriptModules()` without an exemption breaks a passing test.**
   `.claude/CLAUDE.md:209` names `resources-sync.test.ts` verbatim, deliberately, as the
   enforcement mechanism for the generated-`resources/` rule. Widening the enumeration to
   `.ts` makes the doc-leak assertion fail on that line. Task 1 resolves this with a
   recorded exemption (this codebase's own idiom — `HOSTPATH_ALLOW_LIST`,
   `ALLOWED_CYCLES_THROUGH_REPO_ROOT`), not by dropping test files from the enumeration,
   which would silently lose coverage that holds today.

| static safety check → the module tree it polices | A check that enumerates by hardcoded extension stops matching anything after a rename and reports green while enforcing nothing. This plan's primary threat. |
