that `load-order.test.ts`'s cycle-allowlist assertion had gone **vacuously passing** since Plan

existed in the graph, so `findCyclesThroughNode()` returned `[]` unconditionally and the
assertion passed on an empty-vs-empty match that gave no signal the check had stopped running.

against a live-injected regression.

the tracked tree** (`/tmp/.../scratchpad/vice-scratch`, deleted after use; `git status
--porcelain` confirmed empty before, during and after):

   stood at `e63320f^` (immediately before Plan 08's fix commit) into the scratch copy, injected
   the exact cycle regression (an unconditional `import { repoRoot } from "./repo-root.ts"` plus
   a guarded module-scope call in a scratch `hostpath.ts`), and ran it: **7/7 pass — the
   pre-fix guard genuinely does not fail against a live-injected cycle.** This independently
   confirms the vacuous-pass claim; it was not simply taken on faith.

2. **Confirmed the post-fix (current, tracked) guard now discriminates.** Same regression against
   the current `load-order.test.ts` (which uses `resolveModuleByStem("repo-root")`, read directly
