negation. It fires on `adopting` + `mcp` co-occurring in a clause, and the two clauses it
matched in `01.6.1-07-PLAN.md` are both **prohibitions against** that adoption. This file is
the module's documented human overrule for a fallible detector, not a bypass:

- `01.6.1-07-PLAN.md:177` — "**Do not** adopt, import or prepare for any MCP library — that
  is Phase 01.6.3's decision and its seam. **Do not** edit `tsconfig.json`,
  `tsconfig.build.json` or `package.json`."
- `01.6.1-07-PLAN.md:278` — `T-01.6.1-SC` / Tampering / npm-pip-cargo installs, disposition
  **accept**: "No package-manager install task exists in this phase, and this plan explicitly
  forbids adopting or preparing for any MCP library — that is Phase 01.6.3's decision, with
  its own blocking legitimacy checkpoint."
