## D-05 probe mechanism

| Option | Description | Selected |
|--------|-------------|----------|

### Q3 — Probe timeout default, now that the probe runs on the grant path?

| Option | Description | Selected |
|--------|-------------|----------|
| Shorten default to ~1 s, keep the knob | Measured boot ~0.65 s and a live instance answers in milliseconds, so 5 s is time only ever spent discovering an instance is wedged — the case D-05 hunts, now sitting between a session and its emulator | ✓ |
