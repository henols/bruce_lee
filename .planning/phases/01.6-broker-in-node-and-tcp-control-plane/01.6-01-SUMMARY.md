# Phase 01.6 Plan 01: Tracer TypeScript Build Pipeline Summary

**First npm toolchain this repo has ever had (typescript@7.0.2 + @types/node@24.13.3, both exact-pinned and human-approved), proving authored-TypeScript-to-host-JavaScript end-to-end on one real broker tracer module with a durable sync gate and a rewritten CLAUDE.md rule.**

## Performance

- **Duration:** ~45 min, including one checkpoint round-trip
- **Tasks:** 3 (task 1 satisfied by prior approval, no commit; tasks 2 and 3 each produced one commit)
- **Files modified:** 13 (10 created, 3 modified)

## Accomplishments

- Working three-tier build topology proven on one real module: `vice-broker.mts` (authored) -> `tsc` -> `resources/vice-broker.mjs` (banner-marked, committed) -> `install-resources.mjs`'s existing walk (zero code change) -> the host's gitignored `tools/` -> `resources/vice-launcher.sh` (hand-authored, container-guarded) -> `exec node`.
- The emitted artifact was verified, live, to run to completion under a bare `node` invocation from a directory with no `node_modules` anywhere in its ancestor chain -- the mechanical proof that the host needs `node` and nothing else.
- The broker record's refuse-to-clobber guard (live pid, or any `heartbeat_at` presence) and never-throw read discipline were both exercised against real fixtures, not merely asserted in the abstract.
- `resources-sync.test.ts` was demonstrated live to fail on a stale committed build and pass again after rebuilding -- the exact silent-bad-deploy scenario criterion 3 exists to prevent, closed with evidence rather than by inspection alone.
- `CLAUDE.md`'s Emulator Access section now names three tiers instead of an instruction that would have sent a future maintainer to hand-edit a build artifact.
