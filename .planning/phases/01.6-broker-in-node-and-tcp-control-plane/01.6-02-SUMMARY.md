## Decisions Made

See frontmatter `key-decisions` for full reasoning. Summarized:

1. Path-agreement rewrite substitutes `vice-broker.sh` for the deleted `vice-pool.sh` — confirmed their `pool_dir=`/`supervisor_dir=` defaults agree by reading both scripts' own default-assignment lines, not assumed.
2. The launcher's `--print-paths` output is deliberately NOT byte-identical between `resources/` and `tools/` copies (self-referential `self_dir`/`broker_artifact`) — discovered empirically when the first draft's naive byte-identity assertion failed, narrowed to comparing only `repo_root`.
3. The launcher is exempted from the trap-registration assertion (it execs into `node`, replacing its process image, rather than trapping signals itself) while still driven from the same shared script-list constant as the other two checks.
4. `vice.test.mjs`'s "JSON dump alike" assertion uses `JSON.stringify()` directly instead of `formatToolsOutput()`, since that CLI-only rendering helper has no surviving caller once D-05 deletes `vice.mjs`'s entire CLI in plan 04.
5. `install-resources.test.mjs`'s `RESOURCES_DIR` test replaces the hardcoded seven-entry exact-list compare with a `resourceEntries()`-derived non-vacuous check, avoiding a list that plan 04's `vice-pool.sh` removal would otherwise immediately invalidate.

## Deviations from Plan

None requiring an executor deviation rule — every adjustment above is a faithful rewrite decision explicitly invited by the plan's own text ("rewrite it to compare the scripts that survive," "adapting only where the deployed file set has changed," "derive the expected set from `resourceEntries()` ... wherever the assertion allows it"), verified against the actual source of each script/module before being written, not assumed from the plan's prose alone.

## Issues Encountered

- The path-agreement test's first draft asserted full byte-identical `--print-paths` output for the launcher between its `resources/` and `tools/` copies, matching the treatment given to the two bash daemons. This failed immediately with a clear diff (`self_dir`/`broker_artifact` differing, as expected once read against the launcher's own header comment). Fixed by narrowing that specific assertion to the one key (`repo_root`) that is NOT self-referential to the running script's location — resolved within the same task, before committing.

## Known Stubs

None. Every rescued assertion drives real code (`repoRoot()`, `installResources()`, `probeInstance()`/`probeAll()`, `serverInfo()`) against either synthetic temp-directory fixtures or in-process loopback HTTP stand-ins — no placeholder or hardcoded-empty value anywhere in these five files.
