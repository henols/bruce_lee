**Deviation from criterion A's literal filename, recorded.** Criterion A says the artifact is
`resources/vice-broker.js`. It is emitted as **`resources/vice-broker.mjs`** instead, from an
authored `vice-broker.mts`. Reason: the artifact is deployed to `<repo>/tools/`, where there is no
`package.json` at all — Node therefore resolves a bare `.js` file there as **CommonJS**, and an ESM
import statement in it dies with "Cannot use import statement outside a module". `.mjs` is ESM
unconditionally, independent of any `package.json` anywhere on the host. The alternatives were
emitting CommonJS (rejected by RESEARCH §E3: a cyclic `require()` returns a half-built export object
instead of throwing, which is the silent-wrong-answer failure class this codebase rejects) or
deploying a `package.json` into the host's `tools/` directory (intrusive, and `tools/` also holds
tracked RE tooling). The extension now encodes the deployment tier: **host-bound sources are `.mts`
and emit `.mjs`; container-only sources are `.ts` and run from source under native type stripping.**

**Layout decision, and why not `src/`.** RESEARCH.md §A3 recommends option (a), a `src/` sibling
directory. That recommendation does not survive contact with two anchors in this module tree:
`repo-root.mjs`'s branch-4 fallback climbs exactly **three** levels from `<root>/.claude/mcp/<server>/`
and is pinned by a named regression test, and `install-resources.mjs`'s `RESOURCES_DIR` resolves
`resources/` as a plain **sibling** of the module. A `src/` subdirectory breaks the hop count and the
sibling relationship at once. Authored TypeScript therefore stays **flat** in `.claude/mcp/vice/`,
siblings of `resources/`, and the emit target does the separating instead: `rootDir: "."`,
`outDir: "resources"`, `include` a literal host-bound file list.

**Convention this group establishes and 01.6.1 inherits.** A `.ts`/`.mts` file in this group must
not import a `.mjs` module: with `allowJs: false` the typecheck gate rejects it for want of a
declaration file. New tests whose subject is still `.mjs` are therefore authored as `.mjs` and
convert with their subject in 01.6.1. The two test files in *this* plan test emitted output and
authored TypeScript only, so they are `.ts`.

    Create `tsconfig.build.json`: extends `./tsconfig.json`, turns `noEmit` off, sets `rootDir` to
    `.` and `outDir` to `resources`, and sets `include` to a literal one-element file list naming
    `vice-broker.mts` — never a glob. That list IS the definition of host-bound; a module absent from
    it can never reach `resources/` and therefore can never reach the host. This is the mechanism
    that keeps `vice-proxy` container-only when 01.6.1 converts it.

    **The build script.** Create `build.ts`. Export `GENERATED_BANNER` — a function of the source's
    relative path producing the banner text in RESEARCH.md §F: it names the source, states that
    edits are silently overwritten by the next build, and states that an edit made only there
    reaches the host once and is then lost. Export `HOST_BOUND_ARTIFACTS`, the literal expected
    emitted relative paths, today exactly the one broker artifact. Export `build({ outDir })`, which
    runs the pinned compiler against `tsconfig.build.json` with the out-directory overridden to the
    requested path, asserts every entry in `HOST_BOUND_ARTIFACTS` exists there and that nothing
    unexpected was emitted, then prepends the banner to each emitted file. Fail loudly with the
    actual emitted file list when that assertion fails. Give it an `--out-dir` CLI flag defaulting to
    `resources`, so the sync test can build into a scratch directory through the same code path the
    real build uses — the banner must not exist in two implementations.

    **The host-bound module.** Create `vice-broker.mts`, importing from `node:` builtins only.

    Export `parseArgs(argv)` returning the repo root and state directory. `--repo-root` is REQUIRED;
    exit non-zero with a usage line when it is absent. `--state-dir` defaults to `VICE_POOL_DIR` from
    the environment when set, otherwise to the `.vice-supervisor` directory under the repo root —
    matching both `vice-broker.sh`'s own variable and `repo-root.mjs`'s `supervisorDir()`. Taking the
    repo root as an ARGUMENT rather than re-deriving it is the same structural cycle-avoidance
    `install-resources.mjs` documents at its own head, and it stops this becoming a fourth copy of
    the repo-root ladder.

    Export `readBrokerRecordMaybe(path)` — read and parse, treating a missing file, an unreadable
    file, a partial write, malformed JSON or a non-object shape as "not there yet" by returning null.
    Two nested try/catch layers, one for the read and one for the parse, exactly as
    `vice-broker-client.mjs`'s own reader does. It never throws.

    Export `writeBrokerRecord({ stateDir })`, which creates the state directory recursively, reads
    any existing record via `readBrokerRecordMaybe`, and **refuses** — returning a refusal result the
    caller turns into a non-zero exit naming the offending pid or field — when that record names a
    pid that is currently alive (a zero-signal liveness probe inside a try/catch) or when it carries
    a heartbeat property at all. Otherwise it writes a record whose keys are exactly `pid`,
    `started_at` (an ISO 8601 timestamp) and `node_version` (this process's own version string). The
    write is tmp sibling → mode set to owner-read-write → content → rename, in that order, never in
    place: the same choke-point discipline `write_json_atomic()` uses, preserved rather than
    simplified.

    Two properties of that record are load-bearing and must not be tidied. First, the heartbeat field
    is deliberately absent: `vice-broker-client.mjs` classifies a record without a parseable
    heartbeat as never-started, which is the honest verdict for a broker that is not running, and
    adding the field would make an inert record read as alive and strand every session's proxy on a
    request nobody serves. Second, the refusal is **not** the CR-01 singleton guard — that is Phase
    01.7's, enforced by a TCP listener. This one is narrower: do not clobber a record another process
