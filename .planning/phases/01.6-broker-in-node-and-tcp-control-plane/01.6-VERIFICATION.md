- `written_by: "vice-broker.mjs"` — the TypeScript-derived broker, not the 2,103-line
  `vice-broker.sh`. This alone answers truth 14: `vice-launcher.sh`'s `exec node` reached a
  working host `node` and ran the emitted artifact to the point of writing this record.
- `node_version: "v22.22.0"` — **present**, non-empty, a plausible real Node version string. This
  is the exact key whose absence was the sole blocker on 2026-08-03. Answers truth 13 directly.
- `heartbeat_at` is present at `17:17:16Z`, over 8 hours after `started_at` (`08:44:14Z`) — this is
  not the 190-line tracer's one-shot write (which deliberately omits `heartbeat_at` per
  `vice-broker.mts:14-20`, confirmed in the 2026-08-03 report's own investigation and independently
  in 01.6.1's UAT test 3 `investigated_live` block); it is a real process with a poll loop that has
  been alive and reporting for hours.
- `control_host`/`control_port`/`control_token` are populated — the TCP control plane this phase's
  goal names is live, not scaffolded.
- ROADMAP.md line 1064 (Phase 01.8, HV-01) independently corroborates the same read and adds three
  warm spares at 6600/6601/6602 each with an `epoch.json` naming a real `x64sc` pid — consistent
  with `base_port: 6600` and `spares_target: 3` above.

**Caveat stated explicitly, not glossed over:** the running deploy is dated 05:43 (per the task
brief), which **postdates** 01.6.2 (where `node_version` was scheduled to arrive honestly) but
**predates** 01.6.2.1. The record above carries `spares_target` — the pre-rename key — rather than
`warm_floor`, which 01.6.2.1 renamed it to. That is direct, self-contained proof of the staleness
claim: this record was written by a build that predates 01.6.2.1's rename. **This does not weaken
either backstop.** Both truths (13, 14) are 01.6-era facts about the TypeScript broker existing at
all and the launcher successfully starting it and it stamping `node_version` — not facts about
01.6.2.1's specific lifecycle-policy behaviour. Even the 05:43 build is unambiguously the `.mjs`
broker, which is all these two truths require.
