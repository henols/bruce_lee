## Sampling Rate

- **After every task commit:** Run `node --test .claude/mcp/vice/vice-proxy.test.mjs`
- **After every plan wave:** Run `node --test .claude/mcp/vice/*.test.mjs`
- **Before `/gsd-verify-work`:** Full suite must be green **and** the live-session checks below must have been performed
- **Max feedback latency:** ~35 seconds (full suite); ~10 seconds (quick run)

**Phase gate (non-negotiable):** a green full suite alone must NOT be treated as phase-complete.
The roadmap states verification for this phase "is a live session call and nothing else" for
criteria 1, 3 (live half) and 4.

## Manual-Only Verifications

The project convention is `human_verify_mode: end-of-phase`, so these batch into one checkpoint
rather than interrupting each wave.

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| `vice_diagnose`, `vice_recycle`, `vice_result_continue` are callable by name from a normal agent session | C1 | `node --test` talks to a **fresh** child process running current code, so it can never exercise Claude Code's client-side tool-schema snapshot — the layer where the failure actually lives. A test asserting this property already passes while the session disagrees. | From a **fresh** session (the snapshot is taken at session init and never refreshed): resolve each of the three names via `ToolSearch`, then call each one. A successful call — not a green test — is the evidence. Record which session and when. |
| `mcp__vice__tools_call` / `mcp__vice__tools_list` are absent from a real session's tool surface | C3 (live half) | Removal from the forwardable surface is unit-testable; *absence from what a session was handed* is a client-side fact the container cannot read. | From a fresh session, confirm neither name resolves via `ToolSearch` and that no route accepts a deny-listed name nested in arguments. |
| A spawned `gsd-executor` subagent's received tool schema contains `mcp__vice__*` entries | C4 | Requires actually dispatching a subagent and inspecting what it was handed. The frontmatter grep is a necessary-but-not-sufficient proxy: `.claude/agents/gsd-executor.md` was confirmed **gitignored and untracked** on 2026-08-02, so the 2026-08-01 fix is fragile and must be re-verified live, not cited. | Dispatch a `gsd-executor` (or equivalent restricted subagent), have it report its own visible `mcp__vice__*` tool names, and record the result. If absent and the cause is upstream (`anthropics/claude-code#13898`-class), the deliverable becomes a documented session-shape constraint — **not** a CLI escape hatch, which is the prohibited second route. |
