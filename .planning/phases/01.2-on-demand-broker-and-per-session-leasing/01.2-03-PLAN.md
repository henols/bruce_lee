<objective>
Make a missing broker diagnosable in one read, and make sure it can never cost a session its
emulator access.

Purpose: one generic "broker unavailable" sends the reader to the wrong fix two times out of three,
and an agent that hits it is otherwise quite likely to route around it into the shell path 01.1
removed. A dead stdio server is never auto-reconnected, so the proxy exiting or caching a negative
result costs the whole session — which makes "report, never exit, never cache" a hard requirement
rather than a quality goal.

Output: three broker-absent states with three messages and three fixes, an explicit warming-and-retry
cold path that fails fast, a per-server tool-call timeout committed in `.mcp.json`, and an honest
treatment of the one client setting this repo structurally cannot commit.
</objective>
